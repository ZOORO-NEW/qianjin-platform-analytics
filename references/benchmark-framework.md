# 对标账号拆解框架

> 用于 SKILL.md §4.2 对标账号拆解。取赛道内 TOP 5-10 账号，从 5 个维度拆解。

## 一、对标选取标准
1. 同赛道、同平台（或跨平台同赛道做参照）
2. 粉丝量级分层：头部(100w+) / 肩部(10-100w) / 腰部(1-10w) / 新锐(<1w 但涨速快)
3. 至少包含 1-2 个「新锐黑马」——它们的打法对新号最有借鉴意义
4. 排除：明显投流堆量、非自然增长、与用户定位不符的

## 二、五维拆解表

| 维度 | 采集字段 | 说明 |
|------|---------|------|
| 基础数据 | 粉丝量、作品数、均播 / 均赞、爆款率 | 规模与质量 |
| 更新节奏 | 频率(条/周)、黄金时段、稳定性 | 可复制的节奏 |
| 内容结构 | 选题分布、形式占比、系列化 | 内容矩阵 |
| 人设定位 | 语气、记忆点、差异化 | 为什么被记住 |
| 爆款规律 | 高互动内容共性(标题/开头/钩子/情绪) | 可复用的方法 |

## 三、爆款规律提取方法
对每个对标账号取近 30 天互动 TOP3 内容，归纳：
- **标题公式**：悬念 / 数字 / 反常识 / 痛点 / 情绪
- **前 3 秒钩子类型**：提问 / 反常识 / 结果前置 / 故事开场
- **情绪触发点**：共鸣 / 争议 / 惊喜 / 实用
- **结构套路**：清单体 / 对比体 / 故事体 / 干货体

## 四、输出到报告
- 每个对标账号一张小表（见 `report-template.md` §三）
- 末尾「对标共性总结」：3 个高互动共性 + 新手可借鉴切入点
